## 2. Tema dan Objek Website

- **Tema:** UMKM (Usaha Mikro, Kecil, dan Menengah).
- **Objek:** KARA SCOOPS.
- **Jenis Usaha:** Penjualan es krim cup.

KARA SCOOPS merupakan usaha es krim cup yang menyediakan berbagai pilihan rasa dengan tampilan produk yang menarik. Website ini dibuat sebagai media informasi dan promosi untuk memperkenalkan produk KARA SCOOPS kepada calon pelanggan.

## 3. Daftar Fitur Website

Website KARA SCOOPS memiliki empat halaman utama, yaitu:

### A. Beranda (index.html)
- Menampilkan identitas dan slogan KARA SCOOPS.
- Menampilkan informasi singkat mengenai produk.
- Menampilkan beberapa produk unggulan.

### B. Tentang (tentang.html)
- Menampilkan informasi mengenai KARA SCOOPS.
- Menampilkan cerita singkat usaha.
- Menampilkan visi dan misi.
- Menampilkan informasi tim KARA SCOOPS.

### C. Menu (katalog.html)
- Menampilkan katalog lima varian es krim.
- Menampilkan nama dan harga setiap produk.
- Menampilkan produk unggulan atau Best Seller.
- Menampilkan informasi keunggulan KARA SCOOPS.

### D. Kontak (kontak.html)
- Menyediakan formulir kontak pelanggan.
- Menampilkan informasi WhatsApp, Instagram, dan Facebook.
- Menampilkan jam operasional usaha.
- Menyediakan validasi input formulir.

## 4. Teknologi yang Digunakan

- **HTML5:** Membuat struktur dan konten halaman website.
- **CSS3:** Mengatur tampilan, warna, tata letak, dan responsivitas website.
- **JavaScript:** Menambahkan interaksi dan validasi formulir.

## 6. Kendala dan Cara Mengatasinya

Beberapa kendala yang dihadapi selama proses pembuatan website antara lain:

1. **Kendala:** Mengalami kesulitan dalam mengatur tata letak dan tampilan website.  
   **Cara mengatasi:** Memperbaiki pengaturan CSS dan menyesuaikan elemen agar tampilan lebih rapi.

2. **Kendala:** Formulir kontak belum menampilkan notifikasi setelah tombol diklik.  
   **Cara mengatasi:** Memeriksa kembali pemanggilan file JavaScript, struktur HTML, dan fungsi pada formulir.

3. **Kendala:** Mengalami kesulitan saat menghubungkan website dengan GitHub.  
   **Cara mengatasi:** Menggunakan fitur upload file pada GitHub dan memastikan seluruh folder serta file sudah tersusun dengan benar.

## 7. Cara Menjalankan Website

1. Buka folder project menggunakan Visual Studio Code.
2. Buka file `index.html`.
3. Jalankan website menggunakan ekstensi Live Server.
4. Website akan terbuka melalui browser.
